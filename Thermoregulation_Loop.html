Part 1 — Walk the Loop (Simple mode)

1. Switch to Walk the Loop mode, leave the ambient slider at Neutral (0), and click through one full cycle. In one short phrase per stage, what did each box say?

Part 2 — Pushing to Decompensation

3. Reset, then run the Heat wave + exertion (+9) preset at 3× or 6× speed. Watch the Danger Scale — which zone is core temperature in the moment the status badge turns red (DECOMPENSATED)?
4. Keep watching the Activity Log. At what temperature did it announce "Entered Heat Stroke zone"? Did that happen at the same moment the badge turned red, before, or after — and why do you think that is?
The log announces "Entered Heat Stroke zone" at 40.0°C. That's well AFTER the badge already turned red (~38.0°C, still in the Fever zone). The badge status is based on whether the trend is worsening, so it can flag trouble long before core temperature reaches a clinically dangerous zone.

Part 3 — Advanced Mode: Isolating Variables

6. Reset to normal physiology, switch to Advanced mode, and apply the Impaired sweating (dehydration/aging) preset with the ambient slider at 0. Does the loop decompensate at rest? Now raise the ambient slider slowly — at roughly what value does it decompensate? How does that compare to the heat-wave threshold you found in Question 3 with normal effector capacity?
No — at rest (ambient = 0) there's no heat load, so core temp stays at set point and the loop never decompensates, even with impaired sweating. Raising the ambient slider, it starts to decompensate once the load reaches roughly +3 to +4 — compared to about +8 to +9 with normal effector capacity. Impaired sweating roughly cuts the safety margin in half.
7. Compare Peripheral neuropathy (sensitivity ↓) against Impaired sweating (capacity ↓) at the same ambient load (try +5 for both). Which statement best describes the difference?
8. Run the Fever preset. Does the status badge ever turn red? Why or why not — connect your answer to how this activity defines "decompensated."
No — the badge never turns red. Jumping the set point to 39°C does create a temporary deviation, but the effector still has full capacity (1.0×) available to close that gap, so the loop settles into a new compensated state at 39°C. "Decompensated" in this activity means the loop CAN'T correct the deviation — not that the set point moved.
